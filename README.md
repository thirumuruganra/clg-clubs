# WAVC (What's Active in Various Clubs)

WAVC is a campus clubs platform for SSN students and club admins. It helps students discover what is happening across clubs, register for events, and stay connected, while giving club teams a single place to publish events and manage participation.

## App Features

### Student Features

- Google sign-in with SSN account access.
- Personalized event recommendations based on selected interests and followed clubs.
- Centralized event discovery across campus clubs.
- Calendar view for upcoming club events.
- Club browsing with follow and unfollow support.
- Event RSVP flow for quick registration.
- Attendance check-in through event QR links.
- Activity history for attended events.
- Event details for both free and paid events, including fees, payment links, and payment QR codes.
- Add event details to Google Calendar from the student event view.

### Club Admin Features

- Dedicated club admin dashboard.
- Club setup and profile management.
- Event creation, editing, and deletion.
- Poster upload for events.
- Payment QR upload and management for paid events.
- Attendance QR generation and open/close controls for check-in.
- RSVP monitoring for each event.
- Attendance tracking and payment status updates for registered students.
- Bulk payment status updates for event participants.
- Club follower visibility.
- Club member management.
- Event workforce assignment for club members and volunteers.

### Experience Highlights

- Separate student and club-admin flows.
- Role-based routing after sign-in.
- One shared platform for event discovery, registration, attendance, and club operations.
